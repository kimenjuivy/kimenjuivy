### 01 · ✈️ Global Airline Performance Analytics

**[View Repository →](https://github.com/kimenjuivy/airline-performance)**

An end-to-end analysis of **7,001,619 US domestic flights** using 2025 Bureau of Transportation Statistics data. The project covers raw data processing, MySQL database development, statistical analysis and an interactive six-page Power BI dashboard.

**Key Findings**

| Analysis | Result |
|:---|:---|
| Correlation: carrier & late-aircraft delay vs. weather delay | 0.60–0.67 vs. 0.32 |
| Seasonal delay swing: July vs. September | 24.55 min vs. 12.05 min |
| Worst single route (at least 100 flights) | CKB → SFB: 93.98 min average |
| Third-party reference-data errors identified and corrected | 4 |

**Technical Work:** Data pipeline development, SQL querying, statistical testing, data validation, dashboard development and debugging.

`MySQL` `Python` `pandas` `dask` `SciPy` `statsmodels` `Power BI` `Excel`

### 02 · 🛍️ Olist E-Commerce: Customer Retention & Delivery Analysis

**[View Repository →](https://github.com/kimenjuivy/Olist-customer-retention-and-delivery-analysis)**

An analysis of **96,478 delivered orders** from Brazil's Olist marketplace (September 2016 – August 2018). The project investigates customer retention, purchasing behaviour and the relationship between delivery performance and customer satisfaction.

**Key Findings**

| Analysis | Result |
|:---|:---|
| Customers who purchased only once | 97.0% |
| Month-1 retention (size-weighted) | 0.48% |
| Loyal repeat customers | 0.24% (228 customers) |
| Average spend: loyal vs. one-time buyers | R$506.79 vs. ~R$160 |
| Orders delivered later than Olist's estimate | 8.11% |
| Average review: on-time vs. late delivery | 4.29 vs. 2.57 |
| Effect size of delivery delay on review scores | Cohen's d = 1.45 |
| Monthly late-delivery rate vs. average review score | r = -0.86 |
| Late-delivery rate: Rio de Janeiro vs. São Paulo | 13.5% vs. 5.9% |

**Technical Work**
- Developed customer-level RFM segments.
- Conducted cohort-based retention analysis.
- Applied Welch's t-test and effect-size analysis.
- Examined geographic differences in delivery performance.
- Prepared datasets and visualisations for an interactive Tableau dashboard.

**Dashboard:** [Add Tableau Public link]

`Python` `pandas` `NumPy` `SciPy` `Matplotlib` `Jupyter` `Tableau Public`

### 03 · 🇰🇪 Kenya County Development and Opportunity Index (KCDOI)

**[View Repository →](https://github.com/kimenjuivy/kenya-development-index)**

A county-level socioeconomic development index covering **all 47 Kenyan counties**, built from KNBS government publications, including census data, poverty reports, financial inclusion surveys and county GDP figures.

The project extracts and validates eight independent data domains, constructs a composite Development Score using two approaches and examines development differences between ASAL and non-ASAL counties.

**Key Findings**

| Analysis | Result |
|:---|:---|
| Development score gap: non-ASAL vs. ASAL | 0.84 points |
| Effect size of development gap | Cohen's d = 1.13 |
| Statistical significance | p < 0.001 |
| GDP variance explained by poverty + electricity | 67% (Adjusted R² = 0.670) |
| Rank agreement: equal-weight vs. PCA scoring | Spearman r = 0.9993 |
| Domains excluded due to insufficient reliable data | 2 of 10 |

**Technical Work:** Government data extraction, PDF processing, data validation, composite index construction, PCA, statistical testing and cross-validation.

`Python` `pandas` `SciPy` `statsmodels` `scikit-learn` `pdfplumber` `SQLite` `Excel`

### 04 · 🏥 Nairobi Healthcare Access Inequality Analysis

**[View Repository →](https://github.com/kimenjuivy/nairobi-healthcare-access-analysis)**

A spatial analysis of healthcare access inequality across Nairobi's constituencies. Developed a **Healthcare Access Inequality Index (HAII)** combining healthcare facility density, KEPH-weighted facility levels and population pressure, using 2017 KMHFL facility data and 2019 KNBS population estimates.

**Key Findings**

| Analysis | Result |
|:---|:---|
| Level 4+ hospitals concentrated in five constituencies | 75.7% |
| Mathare facility density vs. Nairobi average | 0.73 vs. 1.96 per 10,000 |
| Kasarani population without Level 4+ access | 780,656 residents |

**Technical Work:** Geospatial data processing, facility classification, population analysis, index construction and interactive mapping.

`Python` `pandas` `GeoPandas` `Folium` `KMHFL 2017` `KNBS 2019`
